## Ключевые ответы

**DOM:** представление HTML в виде объектов браузера. JavaScript находит эти объекты
и меняет текст, атрибуты, классы, стили или добавляет новые элементы.

**querySelector / querySelectorAll:** первый возвращает один элемент, второй -
коллекцию совпадений. Символ # выбирает ID, точка выбирает класс.

**textContent:** меняет текст. Введённое имя выводится как текст, а не выполняется как HTML.

**setAttribute:** меняет атрибут. В галерее меняются src, alt и href.

**Объект и метод:** exerciseLibrary содержит массив items и методы findById,
getByCategory, getCategoryLabel. Внутри метода this.items относится к данным этого объекта.

**Массив:** упорядоченная коллекция. В items девять объектов упражнений.

**for...of:** перебирает значения коллекции. Для каждого упражнения создаётся карточка.

**filter / find / map / forEach:** filter возвращает подходящие элементы новым массивом;
find возвращает первое совпадение; map создаёт массив результатов;
forEach вызывает функцию для каждого элемента, не создавая массив результатов.

**Higher-order function:** принимает другую функцию аргументом или возвращает функцию.
Здесь filter, find, forEach и map принимают callbacks.

**Callback:** функция, переданная другой функции. navigateStep(1, renderStep)
получает renderStep, а затем вызывает renderCallback(state.step).
Передаём renderStep без скобок, чтобы не вызвать её заранее.

**addEventListener:** назначает функцию для события: click - нажатие, keydown -
клавиша, submit - отправка формы.

**event.preventDefault():** отменяет стандартное действие. В форме не допускает
отправки; в обработанных стрелках не даёт странице прокручиваться.

**switch:** выбирает ветку по значению. В проекте обрабатывает категорию и клавишу.
break завершает ветку; default обрабатывает остальные значения.

**Состояние формы:** state.step хранит шаг, attemptedStep - попытку проверки,
completed - завершение. Поля не пересоздаются при Next/Back, поэтому значения
сохраняются. При Reset и закрытии форма очищается. После успеха пароли очищаются.

**DocumentFragment:** временный контейнер новых элементов. Сначала наполняем его,
затем вставляем коллекцию в страницу через replaceChildren.

**Звук:** один audio с локальным WAV. Перед повторным запуском pause() и
currentTime = 0 останавливают прежнее воспроизведение. play() возвращает Promise;
возможный отказ обрабатывается через catch. Sound: Off отключает воспроизведение.

**Анимация:** вставка карточек после фильтра запускает CSS-анимацию;
миниатюра вызывает image.animate. Длительность задаётся в миллисекундах.
prefers-reduced-motion сокращает или отключает движение по настройке пользователя.

## Если преподаватель попросит изменить код

- Добавить упражнение: новый объект в exerciseLibrary.items с уникальным ID,
  существующим изображением, категорией и ссылкой. Оба блока создаются из данных.
- Поменять фильтр: изменить getByCategory и объяснить условие filter.
- Изменить длину пароля: изменить проверку < 8 в getFieldError, сообщения,
  HTML minlength и подсказки во всех формах.
- Громкость: audio.volume = 0.35. Допустимый диапазон от 0 до 1.
- Замедлить галерею: duration: 240 в image.animate.
- Замедлить карточки: 240ms в css/advanced.css.
- Убрать переход по кругу в меню: заменить вычисление через % ограничением границ.
- Добавить клавишу: новый case в switch(event.key) с назначением nextIndex.

## Границы проекта

Это frontend-демонстрация. Создания аккаунта, сервера подписок и хранения паролей нет.
Выбран разрешённый вариант с многошаговой формой, поэтому асинхронный POST не требуется.
Для атрибутов выбрана галерея; остальные примеры из OR-группы выполнять не нужно.
Контактная форма открывает настроенную почтовую программу после проверки.
Публикацию и проверку публичной ссылки нужно выполнить перед сдачей.
